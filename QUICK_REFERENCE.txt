## Common Issues & Fixes

### Google Maps Not Showing
- Verify API key is correct
- Check API is enabled in Google Cloud Console
- Clear browser cache
- Check browser console for errors

### QR Code Not Working
- Verify form link is correct
- Test link in new browser tab
- Ensure form is accessible
- QR code size should be at least 200x200px

### Animations Not Working
- Enable JavaScript in browser
- Update browser to latest version
- Check CSS file is loaded (check Network tab)

### Responsive Design Issues
- Test on actual mobile devices
- Clear browser cache
- Check media queries in styles.css

## How to Find Your Venue Coordinates

1. Go to Google Maps (https://maps.google.com)
2. Search for your venue
3. Right-click on the marker
4. Click on the coordinates that appear
5. Coordinates will copy to clipboard
6. Format: lat: 17.3850, lng: 78.4867

---

## Creating RSVP Google Form

Steps:
1. Go to https://forms.google.com
2. Click "Create new form"
3. Add title "Wedding RSVP"
4. Add these fields:
   - Guest Name (Short answer)
   - Number of Guests (Multiple choice: 1, 2, 3, 4+)
   - Will You Attend (Yes/No)
   - Dietary Restrictions (Short answer)
5. Click Share button
6. Copy the form link
7. Paste into script.js line 10
