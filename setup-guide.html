🎊 Wedding Invitation Website - Setup Guide

🎉 Congratulations! Your wedding invitation website is ready. Follow these steps to customize it with your details.

Edit Bride & Groom Names

Update Names in index.html

  1. Open index.html in a text editor
  2. Find the section around line 87-95 (look for "The Bride" and "The Groom")
  3. Replace <h2>Priya</h2> with your bride's name
  4. Replace <h2>Akhil</h2> with your groom's name
  5. Update Telugu translations as needed
  6. Save the file

Configure Ceremony Details

Update Dates, Times & Venues

  1. Find each ceremony card in index.html (around lines 105-150)
  2. Update the following for each ceremony:
    • Date (format: "Month DD, YYYY")
    • Time (format: "HH:MM AM/PM")
    • Venue (location name and address)
  3. You can add or remove ceremonies by copying/deleting ceremony cards
  4. Save the file

Setup Google Maps

Get API Key & Configure Location

  1. Go to Google Cloud Console
  2. Create a new project or select existing one
  3. Enable "Maps JavaScript API"
  4. Create an API key (Credentials section)
  5. Copy the API key
  6. Open index.html and find line 11 with <script src="https://maps.googleapis.com/...">
  7. Replace YOUR_API_KEY_HERE with your actual API key
  8. Open script.js and find line 36
  9. Update venue coordinates:
    • lat: 17.3850 - Replace with your venue latitude
    • lng: 78.4867 - Replace with your venue longitude
  10. Find your coordinates on Google Maps by right-clicking your venue
⚠️ Important: Restrict your API key to your domain only. This prevents unauthorized use of your API key.

Create QR Code for RSVP

Setup Google Form & QR Code

  1. Go to Google Forms
  2. Create a new form for RSVP
  3. Add fields: Guest Name, Number of Guests, Dietary Restrictions, etc.
  4. Click "Share" and copy the form link
  5. Open script.js and find line 10
  6. Replace YOUR_RSVP_FORM_LINK_HERE with your Google Form link
  7. The QR code will automatically generate with this link
  8. Save the file

Update Contact Information

Add Your Phone, Email & WhatsApp

  2. Update:

Update Family Details

Add Parents & Siblings Information

  1. Find the "Family Details" section in index.html (around lines 288-310)
  2. Update for Groom's Family:
    • Father's name
    • Mother's name
    • Sister/Brother name
  3. Update for Bride's Family with same information
  4. Save the file

Customize Colors (Optional)

Change Color Scheme

  1. Open styles.css and find lines 14-19 (CSS variables)
  2. Modify colors:
    Variable Current Color Purpose
    --primary-color #D4145A Main red/pink
    --secondary-color #FDB750 Gold/orange
    --accent-color #F37335 Accent orange
    --gold-color #FFD700 Gold ornaments
  3. Save the file

Test Your Website

Before Sharing with Guests

  1. Open index.html in your web browser
  2. Check all names and dates are correct
  3. Verify Google Maps shows your venue
  4. Scan QR code to verify RSVP form link works
  5. Test on mobile devices (tablet, phone, desktop)
  6. Check that all animations work smoothly
  7. Verify contact information is correct

Deploy Your Website

Share with Guests Online

Choose one option:

  1. Netlify (Easiest):
    • Go to Netlify.com
    • Drag and drop your folder
    • Your site goes live instantly!
  2. GitHub Pages:
    • Push files to GitHub repository
    • Enable GitHub Pages in settings
    • Your site goes live on github.io
  3. Traditional Hosting:
    • Upload files via FTP to your hosting
    • Access via your domain
